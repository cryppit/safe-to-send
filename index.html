Check an address before you send.

Key wallets work everywhere

A normal wallet address comes from a private key. The same key controls that address on every EVM chain, so funds sent on the "wrong" EVM chain can still be reached by importing the key there. EIP-7702 accounts are key wallets too.

Smart wallets live on one chain

Safes, Abstract wallets and other smart wallets are contracts. They exist only on the chains where they were created. On any other chain the same address has no code and no key behind it. Some can be created there later at the same address; some never can.

SafesSmart accountsCaution

Abstract wallets can't follow you

Abstract runs EraVM, which computes contract addresses differently from standard EVM chains. An Abstract wallet can never be recreated on BNB Chain, Ethereum or Base. ZKsync Era also runs EraVM and has Abstract's wallet contracts, so there its owner can most likely recreate it.

What it tells apart

Every check ends in one of these, from what the chains themselves say.

  • SafeA key wallet, an EIP-7702 account, or a Safe that lives on this chain.
  • CautionA contract here, or a wallet only its owner can still set up on this chain.
  • StopNothing can reach funds sent here: a wallet from another chain, or a token contract.
  • Can't tellNever used on any chain checked, or a chain's RPCs did not answer.
